# 智慧图书馆管理系统

这是一个使用 Vue 3、Vite、Element Plus、Pinia、Vue Router、Axios Mock 适配器和 ECharts 构建的前端图书馆管理后台。

## 技术栈

- **前端框架**：Vue 3 + JavaScript
- **构建工具**：Vite
- **UI 组件库**：Element Plus
- **状态管理**：Pinia
- **路由**：Vue Router 4
- **HTTP 请求**：Axios（自定义 Mock 适配器）
- **图表**：ECharts
- **单元测试**：Vitest

## 已完成功能模块

### 1. 登录与权限
- 管理员/普通用户双角色
- 路由守卫：未登录拦截、已登录重定向
- 普通用户访问管理页自动重定向回仪表盘
- 侧边栏按角色动态显示菜单

### 2. 图书管理
- 图书列表：表格、搜索、分页
- 新增/编辑/删除图书
- ISBN 唯一校验
- 库存非负校验
- 有未归还借阅的图书禁止删除

### 3. 读者管理
- 读者列表：表格、搜索、分页
- 新增/编辑/删除读者
- 学号唯一校验
- 手机号唯一校验与格式校验
- 禁用/启用读者
- 编辑时密码留空不修改

### 4. 借阅记录与库存联动
- 借阅记录列表：状态筛选、分页
- 四种借阅状态：借阅中、逾期、已归还、逾期归还
- 新增借阅（借书）：库存>0、读者状态正常才允许
- 还书：自动判断是否逾期，库存自动回加
- 每次刷新自动根据当前日期计算逾期状态

### 5. 仪表盘
- 统计卡片：图书总数、读者总数、当前借阅、逾期未还
- 图书分类分布饼图
- 热门图书 TOP5 横向柱状图
- 近 6 个月借阅趋势折线图

### 6. 个人中心
- 显示当前用户信息
- 修改密码：验证原密码，两次新密码一致性校验

## 本地数据

所有数据保存在浏览器 localStorage 中，不会丢失：

- `library_mock_data`：图书、读者与借阅记录
- `library_auth_token`：当前登录令牌
- `library_user_info`：当前登录用户资料

**演示数据规模**：
- 100 本图书，覆盖计算机、人工智能、数学、历史、文学、艺术、哲学、国学、科普等 10+ 分类
- 30 位读者
- 80+ 条借阅记录，包含四种借阅状态

**重置演示数据**：点击侧边栏底部的"重置演示数据"按钮，即可恢复初始数据。

## 业务规则说明

1. **库存与借阅联动**：借书时库存减 1，还书时库存加 1；库存为 0 时禁止借阅。
2. **逾期判定**：当前日期 > 应还日期且尚未归还 → 逾期；逾期归还记录标记为"逾期归还"。
3. **删除保护**：有未归还借阅的图书、有未归还借阅的读者，都禁止删除。
4. **读者禁用**：禁用后不能新增借阅，但可以归还已有图书。
5. **数据持久化**：所有 CRUD 操作都保存到 localStorage，刷新页面不丢失。

## 已知限制

1. 纯前端 Mock 项目，无真实后端服务
2. 所有数据保存在浏览器 localStorage，不同浏览器/设备数据不互通
3. ECharts 体积较大（约 350KB gzip），后续可优化路由懒加载
4. 暂不支持深色模式（P2 优先级待开发）
